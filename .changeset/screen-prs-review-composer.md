Screen PRs: review composer — the in-app path to post a GitHub review. Collect line comments from triage/deep findings (＋ review) or write your own, add a summary, pick a verdict (Approve / Comment / Request changes), and post via a confirm dialog. Adds a quick-approve ✓ on queue cards and stacks related PRs (base→head) so you review them in order. First write surface: line comments anchor to the diff where possible and fold into the summary otherwise; the post is guarded by a confirmation.
