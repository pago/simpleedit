The sidebar is now an accordion of Sessions, Backlog and Screen PRs. Backlog and Screen PRs open their list in the sidebar instead of a second column, so the main area gets that width back for the item or PR you picked. Each section remembers its own sidebar width, and ⌘1/⌘2/⌘3 (Ctrl on Windows and Linux) switch between them. A session that finished while you weren't looking gets a blue dot, and the Sessions header shows the most urgent session state even while it is collapsed. Starting a session yourself (⌘T, ✦ Agent, + Term) switches back to Sessions.
