The Claude model picker now lists the models your installed Claude Code CLI offers — the same list as its own `/model` menu, including aliases like `opus` that follow the newest release — instead of a list baked into SimpleEdit. If the CLI can't be asked, a short alias-based fallback is shown. Screen PRs triage now defaults to the `haiku` alias, and settings pinned to `claude-haiku-4-5-20251001` move to it.
