Screen PRs takes line comments from the desktop PR detail: comment on any diff line, on either side, or select a range of lines. Comments can be edited and removed on both the desktop and the phone, and the draft persists across restarts and is shared between the two, so a review started at the desk can be finished on the phone. Before posting, each comment is checked against GitHub's diff, and one that can't be placed on its line moves into the review summary on its own, with its file and line.
